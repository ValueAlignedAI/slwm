## Device outcome

Rate directly visible changes to the main device or an installed component between a pre-cutoff view and after the third action. Qualifying changes are opening/closing a cover or drawer, installation/removal or visible connection of a component, an observable configuration/position on the device, and a visible display/indicator state. Free-hand motion, camera movement and loose tools alone are insufficient. Record changed / visibly unchanged / indeterminate. Require a shared visible device reference in both intervals. Record the changed component/relation. Use a deterministic sample across recordings and families, balancing cases whose future action annotations contain a likely manipulation with unrestricted cases for the labeling panel. Publish this ascertainment, coverage and class frequencies. This endpoint applies to the reviewed cases, with class prevalence affected by selection. Review four unlabeled frames, two per endpoint, with no text, action labels, recording IDs or model scores and blinded temporal orientation. Hide roles during labeling. Reserve masked duplicate cases for within-reviewer checks. Exclude uncertain cases from supervised targets and scoring. Train and test only on distinct recording groups within each fold. Report whether each family supports both states. A confirmatory state claim needs at least 20 readable cases, five changed and five stable in each fold and useful repeat agreement. The target measures a visible configuration, not electrical telemetry.
