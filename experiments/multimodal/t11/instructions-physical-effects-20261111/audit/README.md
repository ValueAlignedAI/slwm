# Blind center review

The numbered sheets show every retained fresh-test pre-action surface center. Read left to right in each row. For each event the full source view appears beside a magnified center. The reviewer saw no spoken text, target verb, model scores, depth-change magnitude or later frame on these sheets. The initial 24-event audit also displayed a later frame; the same reviewer had previously seen those 24 pairs. This is a single-reviewer sensitivity analysis.

The 259 decisions and their source identities can be matched using the index. D means a recognizable physical device or device component was visible at the crosshair. Objects such as cups and paper are separate accessories. Hands, peripheral surfaces, uncertain boundaries and out-of-frame centers are separately coded. The rating does not establish that every surface in a 20 cm patch belongs to that object.
