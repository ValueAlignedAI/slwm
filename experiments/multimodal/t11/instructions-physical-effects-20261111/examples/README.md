# Four audible held-device cases

Each pair comes from one of the 96 new HoloAssist recordings. The earlier directive was chosen without consulting the following action or post-action depth. Each example was selected by a fixed hash among independently audited device-centered cases, one per family. The example features can be replayed directly through the public models. Ground truth and source times are kept separately. [Case provenance and observed outcomes](outcomes.json) · [Run the models](../inference/README.md)
