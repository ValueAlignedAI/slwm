# Can a live policy remember a command after speech stops?

G10's registered calibration task continues to display the requested station in the text stream. High occupancy could therefore coexist with poor memory for the request itself. After the first two context-training seeds, but before measuring this intervention, register a new 256-mission cohort (seed 159071). Compare continuously visible requests with the same requests exposed for four ticks (0.4 s) after each change. A blank condition removes the command throughout. Keep camera, physical state, action history, goal schedule and sensor clock identical at each intervention decision. Closed-loop trajectories subsequently differ because policies act. The physical receiver can remember the last observed command. Report pulse, continuous and blank occupancy, plus the already registered sensor-identical calibration delays. Use all three mixed-context families as frozen controls.

If a hybrid or dense parent loses at least ten occupancy points in two of three seeds with brief instructions, run a matched correction in both architectures across all three seeds. Continue the fixed mixed-context parents for 768 updates on identical fresh simulator and room positions. One arm keeps command visibility continuous. The other makes half of simulated instructions brief, with text targets and expert actions unchanged. Use complete 512-step sequences and the same optimizer reset, learning rate and data in both arms. Hold the experimental test to cohort seed 247667. Report whether brief-command training improves repeated-seed transfer and how it changes standard continuous control. These scores apply to the three simulated goal words. Free-form human speech is measured separately on HoloAssist.
