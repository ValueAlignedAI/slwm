# An instruction that disappears

The high-occupancy main benchmark displays the requested station continuously. A separate 256-mission diagnostic exposed each instruction for four ticks after a new goal. The hybrid lost 59.7, 57.4 and 54.8 occupancy points across three training seeds. Dense GPT-2 lost 57.3, 54.4 and 60.7 points. The sensor, goal and action dynamics were otherwise identical. This distinction matters for using a continuously operating agent whose user speaks once.

Both architectures then received the registered 768-update correction from their variable-context parents. Fresh evaluation used a new set of 256 missions. With brief instructions at test time, the matched continuous-training hybrid achieved 30.3 / 37.3 / 35.6%; brief-instruction training achieved 37.8 / 37.0 / 39.4%. Dense GPT-2 reached 34.2 / 38.0 / 31.7% under continuous training and 28.3 / 31.9 / 36.0% under brief training. Short post-training did not consistently repair command retention. As an engineering control, we retained the eight observable word slots until the next observed command and fed them back into the usual shared encoder. Across nine frozen models and 256 new missions each, every one of the 512 executed decisions reproduced continuous command delivery exactly. This follows from the task rule that a request remains valid until superseded. The cache is an explicit input-memory mechanism. It does not demonstrate learned free-form instruction retention, cancellation handling or general semantic memory. [Registered transient-command test](instruction-memory.md)
