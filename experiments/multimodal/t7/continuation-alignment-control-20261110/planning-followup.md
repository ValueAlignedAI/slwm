# Learned two-decision planning after the simulator oracle

The supervised hidden-cue ranking experiment qualified all four adapter policies. None of their terminal RL comparisons passed the registered promotion criterion. An explicitly post hoc exact-physics diagnostic found that a one-decision greedy choice attained 7.0% final success on the 64 original starting pairs and 12.5% on 64 new pairs. An exact two-decision planner reached 48.4% and 44.5%. Both can inspect the exogenous candidate library one decision ahead. This suggests an intervention in planning horizon that can be tested with new weights and new starts.

Fit one train-only, goal-independent Reacher transition predictor. Supervise endpoints for all 147,456 branches and next joint state for the 12,288 branches actually executed between consecutive observations. Fit the same small joint-state readout on the latent field of each of the four locked supervised adapters. Each readout receives the final shared 128-dimensional state. Its labels are the six observed joint-angle and velocity channels. Lock the transition model and four readouts before opening 64 new start pairs numbered 890000–890063.

For each placement run 24 decisions with identical exogenous proposals, observing only the past and the announced next action library. Compare one and two steps of learned lookahead under each model’s carried goal. Primary success means the fingertip finishes within 3 cm. Secondary controls repeat two-step planning with the initial cue explicitly remembered or with raw proprioception and an explicitly remembered cue. The latter reveals any bypass through state readout or cue memory. For both horizons use the same terminal-step convention. Report paired whole-start intervals on each seed and dense GPT-2. This follow-up is conditional on the completed RL and exact-physics diagnostics and has its own independent test split.
