# G7 supervised action-ranking follow-up

The first frozen scorer remembered part of the cue, but all four frozen models missed the uniform 9.80 cm development regret baseline; supplying the current oracle cue still left large regret. This motivates a separate physical decoder ablation before RL. Fit a common training-only neural endpoint prior in joint-relative coordinates on the same executed branches. Provide that prior identically to raw, hybrid and dense decision heads; their goal estimate must still come from the observed cue history. Record the prior with its oracle goal, its zero-information goal control, the original no-prior supervised arms and reset/shuffled cue ablations. Use both head-only and last-block adapters, the unchanged development promotion criterion and a separate closed-loop test. The physical prior is an explicit conditional bypass, and improved goal-cue use must exceed the corresponding ablations. The original plan and terminal episode partitions remain fixed.
