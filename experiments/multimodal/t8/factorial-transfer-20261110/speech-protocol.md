# Parallel 3090 experiment on the acoustic bottleneck

G7 measured 85% acted-speech and 99% audiobook word error even when the decoder received the correct semantic units. The 3090 will run a separate rate–distortion and source-conditioning experiment while Colab trains the physical-transfer factorial. This experiment does not feed data or gradients back into any factorial arm. [G7 waveform controls](../../t7/continuation-alignment-control-20261110/alignment-and-control.md)

Fit a corpus-balanced acoustic codebook on the G7 training speakers only. Pair adjacent fine log-mel frames, fit a 64-component PCA and quantize eight groups of eight coefficients using 64 centers per group. Test the nested one-, four- and eight-group reconstructions at 46.875 symbols per second per group, or 281.25, 1,125 and 2,250 nominal bits per second. Report the frozen G7 semantic-unit oracle, original PCM, fine-mel reconstruction and constant codes on the identical clips. Bandwidth and code semantics both change between some controls. The one-group arm matches the semantic-unit nominal rate.

Fit identical heads on the four existing frozen 116.50M G6 fields, using only G7 training recordings. Predict all code groups from masked audio, unmasked video or text with 2,048 updates and matched input examples. Use neutral reconstruction and the same Vocos waveform decoder and frozen Whisper-tiny.en scorer throughout the new acoustic cases. Distinguish oracle, predicted, erased and wrong-source results. Also evaluate masked-audio repair by preserving the physically available source frames outside the erased span. The primary generation comparisons concern whole generated waveforms, where no target acoustics are supplied. Report reference word counts and speaker-clustered uncertainty.

The audiobook confirmation uses the first four utterances per speaker by a fixed salted ID hash in the official LibriSpeech test-other partition, with each speaker excluded from G7 training by ID. Source archive MD5 is `fb5a50374b501bb3bac4815ee91d3135`. The separate acted-speech confirmation uses four clips per actor selected by the same fixed-hash rule from the 14 actors reserved for G7's physical timing test. Their timing results were previously examined; their speech waveforms were not used to fit this codebook or any prediction head. The predetermined physical crop and forced-alignment rules admit only enclosed reference words. Report exclusions by reason. Freeze the codec and all four heads before scoring any recognition outputs on these panels.

A better acoustic oracle establishes a synthesis path worth using. A claim that the world state supplies content additionally requires the correctly conditioned waveform to have lower word error than wrong-source and erased controls on independent people, replicated across both seeds.
