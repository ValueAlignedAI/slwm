# Recorded continuous-sensing demo

The two input files are42.325s of recorded AMI data, not generated media. This excerpt includes one bootstrap plus30 automatic listen/look/both/wait decisions. The delivered files were actually replayed on CPU using the exact exported world and actor; replay/ contains decisions, forecasts and invariant-weight/arrival-order evidence. Input features are prepared before replay. The separate P1 report finds no replicated utility advantage over the strongest fixed sensing strategy. This is an operational file replay, not physical robot control.

Run the argv in command.json from the repository root, choosing a fresh output directory. The original corpus is not required for this excerpt. Portable weights and fitted codecs are in ../inference_bundle.
