# Scoring and interpretation

The statistical unit for the primary endpoint is a complete mission. Reuse the same 128 mission seeds for all cells, including a second independent training seed. Report separate two-sided paired percentile bootstrap intervals using 4,000 mission resamples. Each mission contains eight successive goals and 512 interactive decisions. A point estimate from a partial training factorial will be identified as such.

Promotion of the periodic nonlinearity to the expensive 896-wide stage uses only development missions at the wide emitted field. Require greater goal occupancy than GELU for both architectures in each of the two training seeds. A favorable seed or a training loss reduction alone does not pass. The replay and fresh cells share training exposure and real recordings. Compare terminal width and architecture within matching seed, activation, data treatment and trunk size. The held action-history test separately requires physically identical sensor histories and opposite oracle actions in 100% of generated pairs.

On recorded rooms, mask the target sensor at every step. Compare aligned conditional predictions with the training prior and a within-recording half-duration time shift with the same missing target. Report absolute error and relative skill for held audio spectra, RGB camera, tracked spatial measurements and event text. An improvement over a global prior can come from recognizing the room. On ROMA, freeze the backbone, fit the same fixed-regularization force head on six calibration scenes and report future force error on the other eighteen. The raw-sensor head and a persistence rule with observed force are separate controls.

Use the participation ratio of the held covariance spectrum to measure how many directions the shared field uses. Count the number of components that explain 95% of variance. Neither metric indicates the number of semantic concepts. Report hardware time, endpoint cost, simulator episodes, recording minutes and sampled time positions. Each classroom-style command and each event label is short. This study tests grounding with synchronized evidence. Long-form linguistic transfer and open-vocabulary speech synthesis require additional measurements.
