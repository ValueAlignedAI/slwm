# Do the four sensors use the same coordinates?

Reconstruction and successful actions establish that several decoders can read one emitted field. Their scores leave open whether different sources map the same physical event to the same coordinates. Test this directly on the remaining STARSS23 Sony camera recordings in rooms 21 and 22. These recordings were outside every G9 optimization, tuning and previous scoring split. Their official dataset role is dev-train-sony. They are held for this study.

Use all 28 complete recordings and eight equally spaced 32-tick windows per recording. For each of the eight terminal large models, independently encode audio only, vision only, measured geometry only, and event words only. Average the emitted field over the last eight causal ticks. A query must identify its matching window among eight candidates from the same recording, so site, camera identity and coarse scene are held fixed. Compare all twelve ordered cross-source directions with chance 12.5%. Average ties fairly. Subtract each source's within-recording mean before cosine similarity.

Report direct shared-coordinate retrieval first. A separate train-only orthogonal alignment fitted to the 50 TAU training recordings tests whether a small change of coordinate system can recover additional correspondence. Never use Sony pairs to fit that map. Report recording-level scores for each training seed. Short event names, silent intervals and static camera content can be ambiguous. This follow-up can establish limited temporal correspondence and cannot establish source-independent semantics in general.
