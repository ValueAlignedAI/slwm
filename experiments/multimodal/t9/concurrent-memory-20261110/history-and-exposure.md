# Full-history and equal-exposure controls

The first completed G9 large-model pair used 128 emitted coordinates. Its registered simulator result showed a large architecture difference in seed 912. Two alternatives are plausible. Dense attention retained 64 prior clock positions whereas the retention layers could carry state throughout a mission. Also, the larger trunk received 4,096 updates versus 384 for the small screen. These follow-ups were specified after observing that first score.

1. Use independent mission seed 655073 and the same 128 initial worlds, action choices, sensor clocks and 512-step goal sequence across models. Compare the native 64-step attention window, a full 512-step causal attention cache, and resetting every layer of both architectures every 32 steps. Change the attention window in every attention layer of either architecture. Keep frozen weights and causal masks. Publish per-mission occupancy, goal attainment, interval-specific curves, theoretical cache bytes and measured execution time. Attention beyond 32 steps is an inference extrapolation because both models trained on 32-step sequences.
2. Train the small, four-layer GELU trunk from its registered initialization to 4,096 steps with the large stage's optimizer schedule, using both architectures, fields and seeds. Share sample indices, real recordings, masks and training exposures with the corresponding large run. Freeze at 1,024 and 4,096. Comparing matched rungs separates trunk size from exposure and changes the ratio of independent simulator starts to parameters. The support of real recordings is fixed.
3. Use the same protected source and scoring code for both architectures. Report the follow-up cohort separately and retain the original registered result. A native-window win alone supports an advantage under that memory policy. Equal-prefix and full-cache results determine whether the advantage survives these stronger controls.
