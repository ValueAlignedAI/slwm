# Inspect the independent motion labels

The original blinded review covered 130 distinct before/after pairs and 12 hidden repeats. The second review covered 100 uniformly sampled cases on a new acquisition, 35 additional blue-challenge cases and ten hidden repeats. Each view shows two original camera frames, at the early prediction clock and the endpoint, with left/right orientation randomized. The reviewer saw no command, source identifier, split, target class or model result. Ratings are unchanged, red, blue, green, yellow or indeterminate. The outcome is the visually dominant *block color*, independent of arm displacement. The same Codex reviewer completed both panels. [First raw ratings](ratings.json) · [Independent ratings](external-ratings.json) · [Joined decisions and repeat agreement](../metrics/measurement.json)

The public source index identifies each acquisition, original episode, shard and byte offset. Select the indicated row in the source index to reconstruct a case. From the repository root after preparing the registered sources, run `PYTHONPATH=. python scripts/data/g13_object_audit.py` for the first sheets and `PYTHONPATH=. python scripts/data/g13_external_audit.py` for the independent sheets. The decision files distinguish uniform and challenge samples. The latter is intentionally enriched for disagreements concerning blue. All raw camera frames remain available from the publisher.
