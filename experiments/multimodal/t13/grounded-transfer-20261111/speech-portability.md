# Real-waveform portability correction

A normal single-utterance CUDA call and CPU inference disagreed with the CUDA minibatch kernel used to evaluate the original direction encoder. The public input waveform and its cached 64 × 40 features were byte-equivalent. On a concrete held “left” recording, the original weights gave a left probability of 0.349 on CPU and single-clip CUDA, versus 0.995 in an eight- or 128-clip CUDA call. This observation prevented the original speech package from release.

Replace the convolution operator with explicitly padded spatial patches and a high-precision matrix multiplication. Keep the four-word speaker splits, same seeds, optimizer, schedules, recognition targets and development selection. Train the six replacement word encoders anew, then refit the downstream voice probes on training, seal their choices on development and rerun both held robot cohorts. Report CPU, CUDA, single-word and batch parity separately. Keep the six original fits in the scientific accounting. The robot cores were trained on the publisher's hindsight text and the HoloAssist component path uses Whisper and MiniLM. Those studies have independent input lineage.
