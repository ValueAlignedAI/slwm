# A detector repair and an independent replication

The first development sweep selected bound color roles over separated slots (median object NLL 1.200 versus 1.468). The independent linear dynamics baseline reached 4.65 mm on development while the best direct neural fits were near 9 mm. Direct association with the input goal appears learnable. The initial object measurement has an identified failure: among ten development examples labeled blue, the single blinded reviewer saw one definite blue movement, two indeterminate cases and seven definite alternatives. The test quality panel was also audited before model scoring. These observations motivate two separate changes.

1. Preserve the original banks, fit recipes and physical results. Compare detector variants using the **development visual judgments only**. Inspect a stricter saturated-blue mask and bidirectional displacement of the color pixel sets. An object emerging from occlusion typically changes support in only one direction. Freeze the detector using development correct assignments and visibility, and check it on a new blind sample. Retain the original size-matched neural results as a diagnostic of label error.
2. Download four more whole real-robot shards, the next four after the original sixteen in the previously registered hash order. Keep no group sharing a parent ID or even one source-frame fingerprint with the original sixteen shards. Evaluate the corrected methodology on these independently acquired parent groups. Report the original held set and this replication separately. The fresh replication supplies no fitting, scaling, calibration or selection data.
3. Compare ordinary linear system identification with input-dependent response coefficients inferred from causal velocity, prior commands, proposed command magnitude and direction changes. Choose among fixed ridge strengths by development groups. Include an analytic response-only control and learned residuals around that reference, all given the same legal observations. Measure both aggregate and rare large errors. For object prediction compare an explicit training-derived prior over mentioned object roles with learned corrections to that prior. Each architecture sees the same role information. Report whether architecture, representation, measurement or the physical baseline produced any improvement.

This follow-up was prompted by inspectable development errors and independently scored measurements. No G13 robot model predictions on held sources were opened to choose these changes.
