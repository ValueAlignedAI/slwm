# G13 · Which changes make a small shared physical world model transfer?

Register on G12 main `736d1f0` before fitting or examining held predictions. Keep native completed HoloAssist speech as a naturalistic anchor. Add independent, outcome-instrumented real robot trajectories from Google's Language-Table release. This choice tests an error visible in G12: a changed instruction can change the output even when it supplies little information about the scored movement. A platform with measured commands, effector state and before/after object images can separate goal grounding, dynamics, perception and policy selection.

## Studies and decision rules

1. **Natural speech transfer.** Reproduce the recording-balanced three-position G12 action metric. Compare the released early dense, gated and SLWM predictors with a train-only frequency reference and new residual readouts that shrink uncertain predictions toward that reference. Test the value of extra independent annotated demonstrations for learning the mapping from completed speech to actions, without exposing human transcripts at ordinary test time. Select regularization, mixture and data-use choices on the old development recordings only. Evaluate once on up to 12 additional publicly labeled groups per original held family, excluding every G10, G11 and G12 source. Keep the original earlier same-instructor foil, silence, timing guard and ordered triplet definition. Existing G12 test cases may be used for descriptive comparison only.
2. **Physical transfer and architecture.** Acquire sixteen complete Language-Table real shards by SHA-256 ordering of shard name, excluding format pilot 00000. Use whole-source groups, keep all overlapping or relabeled episodes together and check frame identities across splits. Text in this source is a hindsight annotation. Each prediction reads a real image prefix, past measured effector state and earlier control, plus the goal when requested. Separate forecasting a demonstrated movement without future controls from predicting the physical effect of an explicitly supplied proposed control sequence. Predict measured future effector displacement and visible block motion. Test a flat matched dense, a plain gated recurrence and the SLWM with spatially structured, shared object representations. Vary object-centric observation coding and the residual around a physical reference in matched controls. Include zero-motion, constant velocity, command integration, train-fitted system identification, and language/vision-only controls as applicable. Test matched goals, other available goals from the same parent recording and missing goals without changing the scene. Report all opportunities and the eligible paired subset.
3. **Grounded goal, uncertainty and operations.** The visible outcome test uses independently extracted block tracks; it never labels the outcome from the goal sentence. Learn a shared field that proposes an action, a distribution over the moved object, and future state. Compare learned goal binding with a transparent lexical/geometry reference, dense attention at the same parameter count, and language-free processing. Hold out directed color pair compositions from training and tune using separate source groups. Use real human recordings of direction words from Speech Commands for an explicitly controlled audio transfer on compatible real-robot labels, if coverage supports it. These separately recorded utterances are a controlled substitution, distinct from HoloAssist's naturally paired speech. Evaluate a continuous replay with independent uncertainty routing; report both selection coverage and error. Report modality substitutions, failure cases and simple controls alongside any positive result.

Use training-only fitting and normalization. First run a diagnostic and a development sweep; record the numerical reason for advancing a recipe. Freeze choices before opening the confirmatory banks. For a stable process or architecture finding require positive paired 95% whole-source-group intervals in at least two of three training seeds on the declared transfer endpoint. For an architecture claim compare models with the same representation and training information, including the dense Transformer with the same inductive bias at its input/output edges. Record within-source interventions separately from broad acquisition counts. Report exact data scope, model versus frozen-codec parameter counts, checkpoint hashes and accelerator time.
