# Ongoing spoken control

Freeze 16 additional simulation starts, alternating nominal and shifted contact. Eight use the original held speaker pool and eight use the fresh speakers. Each mission presents six human recordings in an assigned order. The four possible cues change either the object or destination. The table keeps running while the new command plays. At the first macro boundary after the last audio sample the calibrated edge can update the goal. A rejected update retains the old goal in the standard condition. Each completed cue has 24 more three-tick control decisions before the next cue starts.

Compare the locked spatial and dense seed-1411 policies, standard geometric feedback, clearing goal memory after one decision, accepting only the first usable goal, and clearing the pending goal after a rejected update. Score placements and unintended motion for each phase relative to the state at the time of the cue update. Bootstrap whole sustained missions. Test already satisfied and absent goals separately. Record complete simulator views with original speech for the first predetermined mission in each cohort, independent of performance. The recorded-speech encoder is evaluated after complete utterances. Source audio runs on the simulator clock and the control loop never resets between goals.
