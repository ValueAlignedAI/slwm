# Remaining action-sequence limit in G1

Structural audit, independent of held-out outcomes. G1 future queries attend the
received field and each query's own supplied command. They do not attend other
future queries or earlier commands in the supplied future plan. Thus changing
the first seven commands while preserving the eighth cannot change the eighth
prediction. Absolute pose targets make this a useful servo-response baseline,
but it cannot represent arbitrary accumulated effects of an action sequence.

The existing1/4/8-step test remains unchanged. Compare it with commanded-pose-as-
state and history/persistence controls; do not call input sensitivity alone
causal physical planning. Offline imitation readouts are also a different claim.

The next dynamics architecture needs a causal action-prefix encoder or recurrent
latent rollout initialized from the received world state, with physical cadence
verified. Compare it to a matched per-command predictor, preserving the last
command while changing earlier commands as a structural control. Predict actual
held-environment consequences before using such rollouts to rank actions toward
an explicit goal/cost. Branching interactions and closed-loop feedback are still
needed for counterfactual/control validation. No current weight or registered
primary test is changed by this audit.
