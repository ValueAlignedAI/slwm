# G4 follow-up registered from development results

Across both pilot seeds, direct missing-stream supervision reduced GRID video-to-audio error relative to observing and reconstructing the same stream. The audio-to-video pixel errors were nearly identical with correct and wrong audio. A lower absolute pixel error can therefore coexist with a model that predicts a typical mouth. This follow-up uses development results only. Pilot confirmation data will be scored with frozen rules.

For a causal motion intervention, supervise per-window centered low-resolution visual trajectories and acoustic envelopes. Score the correct temporal alignment against two eight-tick offsets from the same recording. These foils preserve the recording, speaker and background. The target is used to form the training loss only. At inference the shared encoder still receives a single specified source. Compare the additional loss with the existing cross-only recipe for both dense cores at identical width, depth, data order, sample count and optimizer schedule. Test the held-out correct-versus-wrong gain and generated temporal motion. An increase in motion amplitude alone does not establish better conditional generation.

The separate scale comparison fixes the learning rate, schedule, effective batch and number of examples. Compare 3.61M, 26.04M and 117.11M dense cores with both architectures when the measured TPU window permits. A stratified quarter-data control at the middle size isolates the number of available records while preserving mixture and presentation count. Report any uncompleted cells. The registered 256/1,024/512-update pilot, medium and anchor runs have different budgets, so they are reported as distinct learning regimes.

Independent transfer uses ESC-50 folds 1–3 for labelled support, fold 4 for development and fold 5 for confirmation. CIFAR-10 uses disjoint support and development examples from the official training partition and an exact-image-deduplicated official test subset. Frozen ridge readouts use 1, 4 or 8 labels per class and a raw-feature baseline. For modality interchange, fit an eight-shot GRID command readout on one modality and apply it unchanged to a different modality on held-out speakers.
