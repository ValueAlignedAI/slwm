# AMI source availability revision before fitting

The original source plan reserved ES2011a/ES2012a/ES2013a. All but two requested
signals downloaded; ES2013a.Headset-2.wav / ES2013a.Closeup3.avi did not complete,
and the public server returned403. No reason is inferred and no alternate route
to those unavailable files is used. The original download log and data config
are retained in source_availability_review/ and ami_download.log.

Before fitting any T2-B1 generator or viewing its test scores, replace the whole
ES2013a group with the next numbered group, ES2014a. This preserves12 test people
and verifies disjoint official global identities again. The three downloaded
ES2013a participant tracks remain unopened and outside every fitting/selection/
test set; they are not repurposed for tuning. All training, selection and
calibration participants stay as registered. This is a documented availability
revision, not performance-based filtering. P1-S1 uses the same final reserved
people and remains preregistered before any final scores.
