# G4 conditional generation and shared-state transfer

The completed study includes forty trained endpoints, held-out speech and action controls, three parameter scales, portable weights, long output artifacts and matched TPU/3090 timings. [Measured results](../../experiments/multimodal/t4/crossmodal-state-tpu-20261109/report.md)

The frozen G3 1,000-update development screen recovered useful signal information. The dense signal model beat dense GPT-2 on the three reported tasks in both seeds. Raw features still scored higher on Fashion, and the sparse spoken-digit advantage reversed between seeds. In G3 the continuous heads reconstruct and predict streams that the encoder also receives. The separate caption alignment term does not directly train a video-only field to generate sound. This motivates a controlled intervention. [G3 study](joint_transfer_20261109.md)

## Registered test

Give the encoder one observed modality at a time. A single ordered state must support shared decoders for sound, vision, text and recorded robot state/actions. Compare direct missing-modality prediction against reconstruction of the observed stream with the same encoder, exposure, alignment and output budget. Cross-generation is successful only if matched inputs improve held-out prediction over a shuffled same-domain source and an input-erased clock/control. Condition-sensitive temporal detail and intelligibility require their own measurements. Taking an average image or an average voice is a plausible failure.

Use real GRID audiovisual speech with train-only speakers and sentences, LibriSpeech, Clotho, COCO raster patches and captions, DROID recordings with instruction text and previous commands, and nonoverlapping FineWeb byte-language windows. Keep AMI entirely outside fitting for transfer across recording domain. Preserve the original disjoint speaker, sentence, scene and recording roles. Develop on selection roles only. Freeze endpoints and evaluation code before reporting confirmation. An AMI example is novel to these new weights even though older SLWM experiments used other AMI recordings. The new models start from random weights; the earlier 500M-token language parents form a distinct experiment.

The dense GPT-2-style causal Transformer and dense signal model use the same edge encoders, output heads, width, depth, FFN expansion, sources and number of updates. GPT-2 always uses dense attention and dense MLPs. The signal block uses causal multiscale time filters with learned pointwise gates. The sparse comparison uses an explicitly grouped feed-forward matrix with full-width shared mixing between groups. Record executed and stored weights and attention/filter costs. Compare its reduced active capacity against the dense runs explicitly. No claimed kernel speedup follows from weight count.

Use fixed 64-position arrays and report padding, physical durations, training exposure by source, compiled and warm throughput and validation examples per second. The microbatch sweep uses the real training objective. Freeze a common effective batch before comparing quality. The screen and next scale are registered in the config; only training/dev evidence may select a continuation. Escalate toward the approximately 116M dense core only after a stable medium run, useful validation signal and a measured compute budget. This is an adaptation/learning-curve experiment; repeated windows are reported separately from unique sources.

Evaluate fresh-speaker generation, wrong-recording controls, an unseen recording domain, and frozen few-shot transfer on independent classification problems. Live evaluation uses a chronological unbroken held-out recording for more than 30 seconds, with carried state, an explicit reset control and no target observations fed into the conditional encoder. Report the actual output resolution and codec. Recorded next-action error is an observational metric. A closed-loop decision claim requires an environment with interventions and task returns.

Modality withholding has precedents in audiovisual masked autoencoding. The hypothesis specific to this study is that explicit direction-of-generation supervision can improve conditional output and cross-view transfer beyond caption alignment with observed-stream reconstruction.
